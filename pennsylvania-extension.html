Pennsylvania - State Tax Extension

Individuals  •  Semi-automatic
Form REV-276 (if tax owed)6 monthsFederal extension honored if no PA tax due
← Extension Guide home

An extension to file is not an extension to pay tax.

Pennsylvania's extension is semi-automatic: if you already have a federal extension and don't owe Pennsylvania tax, no separate state form is needed. Form REV-276 is required only if you owe PA tax, need an extension without a federal one, or are paying by check.

Get the form: Download REV-276 (PDF, pa.gov)  •  Extension of Time to File (pa.gov)  •  myPATH

Authority61 Pa. Code §117.14
If you have a federal extension and owe PA tax, PA still requires REV-276 (with payment) - the federal extension alone only substitutes for the state form when no PA tax is due.
