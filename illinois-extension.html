Illinois - State Tax Extensions

Individuals and corporations  •  Both extensions automatic  •  Verified 9-22-2026
Individual: automatic 6 mo.Corporate: automatic 7 mo.No application form
← Extension Guide home

An extension to file is not an extension to pay tax.

Illinois grants both individual and corporate filing extensions automatically, with no application form required to obtain the extension itself. A payment voucher is needed only when tax is owed.

Individuals - Form IL-1040

Pay online or by mail (if tax is owed): Download IL-505-I (PDF, tax.illinois.gov)  •  Extension to file (tax.illinois.gov)  •  MyTax Illinois

Authority

No application form need be filed to obtain either automatic extension. Late-payment penalties and interest accrue from the original due date regardless of a valid filing extension, and a copy of any approved federal extension must be attached to the Illinois return when filed.
